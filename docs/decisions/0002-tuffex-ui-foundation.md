# ADR-0002：Tuffex 作为后续统一 UI 基础

> 记录用户指定的组件体系，并提供有固定版本、可离线检索的开发文档。

状态：`accepted` · 更新：2026-09-13

## 决策

后续宣传主页、内部 Hub、论坛、GitHub 组织管理和扩展服务以 Tuffex 为统一组件基础。完整约定只在 [使用政策](../components/tuffex/USAGE-POLICY.md) 维护，Agent 和设计文档通过链接引用。

[组件文档库](../components/tuffex/README.md) 保存固定提交的官方中文文档、完整示例、类型及实现参考，并生成检索目录、章节索引和文件哈希。

## 实施状态

本次完成的是文档库和项目选型约定，没有安装 Tuffex、替换论坛、迁移 Vue、重做认证或部署页面。现有 React 与 Node 22 保持不变；实际接入须先核对对应发行包的 Vue peer、Node engine 和构建方式。

## 对已有设计的影响

保留 ADR-0001 的统一入口和低耦合模块化原则。旧 React 适配器只服务尚未迁移模块的维护，不再作为新产品 UI 的平行长期选型。安全、可访问性及业务回归要求保持不变。
