# Product introduction

> Portal, forum and GitHub organization administration for the Yangtze University Geek Class.

Status: current. Updated: 2026-09-12.

The portal hosts product information, public documentation, feedback and invitation pages. The forum supports technical discussion. Administration uses the signed-in user's GitHub permissions; forum membership does not grant organization privileges. Archives are read-only.

Never post credentials or sensitive personal information. See the [user guide](../ops/USAGE.en.md).
