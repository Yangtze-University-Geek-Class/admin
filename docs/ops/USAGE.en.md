The forum directly uses Tuff Forum and is served under the `/forum` path of the portal domain (the former forum subdomain is retired). Selecting a sample user is not real login; posts and replies are saved only in this browser. Do not enter sensitive data. Core organization administration still uses GitHub authentication outside its read-only local preview. Production rollout, external authentication and operational verification require separate authorization and evidence.
