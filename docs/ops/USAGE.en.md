# Usage — English overview

> English navigation companion; the Chinese document is the canonical current specification.

Status: current. Updated: 2026-09-23.

See [USAGE.md](USAGE.md) for the complete current document. This overview does not define a second rule set.

The portal's apply form (`/apply`, labelled 投递简历) needs no login and asks for name, class, email and strengths. The email is used to contact you and is never shown on the forum or public pages. Submissions are stored on the server, have no public read endpoint and no online status lookup, so keep the receipt ID shown after submitting and do not include sensitive data such as passwords, ID numbers or home addresses. The forum directly uses Tuff Forum and is served under the `/forum` path of the portal domain (the former forum subdomain is retired). Selecting a sample user is not real login; posts and replies are saved only in this browser. Do not enter sensitive data. Core organization administration still uses GitHub authentication outside its read-only local preview. Production rollout, external authentication and operational verification require separate authorization and evidence.
