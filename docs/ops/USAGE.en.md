# Usage — English overview

> English navigation companion; the Chinese document is the canonical current specification.

Status: current. Updated: 2026-09-25.

See [USAGE.md](USAGE.md) for the complete current document. This overview does not define a second rule set.

The portal's join form (`/join-us`, labelled 加入我们; the old `/apply` address redirects there) needs no login and asks for name, class, email and strengths. The email is used to contact you and is never shown on the forum or public pages. Submissions are stored on the server, have no public read endpoint and no online status lookup, so keep the receipt ID shown after submitting and do not include sensitive data such as passwords, ID numbers or home addresses. The home page is a 3D desk that boots into the YUGC OS desktop; its latest-topics and public-repository widgets are dated snapshots, not live data. The forum directly uses Tuff Forum and is served under the `/forum` path of the portal domain (the former forum subdomain is retired). Portal, forum and console share one GitHub sign-in: signing in or out in one place applies to all three. Only members of the 极客班 GitHub organization can sign in; anyone else (including invitees who have not accepted yet) returns to the page they came from with an explanation, and can still read the portal and forum posts without signing in. The forum has no sign-in of its own and posting or replying is not open yet; old forum accounts are not linked to GitHub sign-ins yet. In the forum demo mode, selecting a sample user is not real login; posts and replies are saved only in this browser. Do not enter sensitive data. Core organization administration uses the same GitHub sign-in; the local preview only connects to GitHub when a maintainer provides local OAuth app credentials. Production rollout, external authentication and operational verification require separate authorization and evidence.
