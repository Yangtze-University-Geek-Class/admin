# 用户指南

> 公开访问说明：投递简历、核心 GitHub 管理和新论坛浏览器演示分别怎么用；不包含内部凭据。

状态：`current` · 更新：2026-09-23

## 官网和论坛

宣传主页可公开浏览。论坛已切换为采用 Tuff Forum 原代码的新界面，提供话题、分类、标签、搜索、回复、书签、通知和用户页面，位于站点域名下的 `/forum` 路径。当前为本机预览阶段，不是生产内部社区：本机发现私有快照目录时只读显示极客班论坛归档，否则为上游示例。正式站点（`yangtzeu.work`）与预发布站点（`prev.yangtzeu.work`）是两套完全独立的部署，各自的数据、账号与登录态不互通。

快照模式下没有登录、发帖、回复或资料修改，「登录」只打开只读说明。示例模式下示例身份选择不是真实登录，发帖/回复/点赞等只保存在当前浏览器；换浏览器不会同步，清理浏览器数据或点击“重置示例数据”会丢失这些修改。不要填写真实密码、隐私资料或需要长期保存的信息。重启预览服务不会主动清空浏览器存储。

旧论坛 API 已停用，旧页面入口跳到新论坛首页，不自动将旧帖子编号映射到新主题。旧账号、帖子和附件未删除，也未导入可写的新论坛数据库。

## 投递简历

官网首页的「投递简历」入口打开投递表单（`/apply`），不需要登录。需要填写四项：

- 姓名：2–40 个字符。
- 班级：2–40 个字符，只能使用中文、字母、数字、空格、`·` 和 `-`。
- 邮箱：不超过 120 个字符。我们用它联系你，它不会出现在论坛或公开页面。
- 个人特长和优点：10–2000 个字符。写具体做过什么、擅长什么、想做什么。

提交前，页面会在浏览器里做一次短暂的防滥用计算；站点开启人机验证时，还要先完成验证。同一来源地址一分钟内最多提交 5 次。提交成功后，页面会显示投递编号和提交时间，请自己记下编号，后续沟通时可以提供。网站目前没有在线查询投递进度的页面，我们阅读投递后会通过你填写的邮箱联系你。

投递内容保存在服务端数据库，用于我们阅读投递并联系你，不通过任何公开接口返回。不要在表单里填写密码、身份证号、家庭住址等与投递无关的敏感信息。

## GitHub 组织管理

核心后台保留 GitHub OAuth，根据真实组织和仓库权限操作。论坛示例身份不替代 GitHub 权限。本机核心预览未连接真实 GitHub，样板页面只读。破坏性操作需确认，取消不执行；真实操作须有对应授权。

## 邀请和反馈

邀请可能过期、禁用或达到额度。真实邀请发送后需在 GitHub 接受；同一收件人重试复用结果，提示待核对时不要反复点击。反馈可能公开摘要和回复，勿提交敏感信息，不保证即时通知。
