# conventions/

> 强制遵守的规范：提交、Issue、PR、贡献流程。违反会被 PR review 退回。

| 文件 | 什么时候读 |
|---|---|
| [`CONTRIBUTING.md`](./CONTRIBUTING.md) | 第一次参与，或需要确认分支/部署/沟通约定 |
| [`COMMITS.md`](./COMMITS.md) | 写 commit message 之前 |
| [`ISSUES.md`](./ISSUES.md) | 提 issue 之前（含查重流程） |
| [`PULL-REQUESTS.md`](./PULL-REQUESTS.md) | 开 PR 或 review PR 之前 |

这些规范是**强制**的。`AGENTS.md` §0 把这些文件列进了改动类型映射表，改代码前必须先读对应那篇。
