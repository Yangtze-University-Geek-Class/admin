## 套件定位

基础套件是日常界面的主体，七个分组从原子到路径逐层展开：**通用**（按钮、图标、头像、徽标）、**表单**（输入、选择、日期、开关、上传）、**布局**（容器、栅格、卡片）、**导航**（标签页、面包屑、菜单）、**数据展示**（表格、树形、时间线）、**反馈**（弹窗、抽屉、进度）与**状态占位**（空态、错误、骨架屏）。全部组件经 `@talex-touch/tuffex/base` 分类入口按需引入。
