组件目录、任务映射、轻量 llms 导航和 catalog 机器索引都已提供。查询支持中文、组件名、Tx 标识；可选正文搜索定位具体 API 参数；按章节/行号读取有输出上限和继续命令。

根 AGENTS、docs 导航、设计/技术栈/共享模块文档已经引用 Tuffex 使用政策，后续新增及迁移 UI 以它为统一基础。原始文档和代码以 .txt 保存，不执行上游脚本、不参与业务编译、不自动发布到公开文档 API。现有 web 与并行迁移模块按各自 manifest 区分，不从本文推断全项目的框架和迁移状态。

## 范围与限制

本任务只增补组件开发文档、检索工具、检测入口和选型规范；没有安装/升级业务依赖，没有提交、推送、部署、重启服务或操作业务数据库。工作树中的其他论坛迁移改动保留，未被本任务覆盖。

文档检索和完整性通过，不等于所有第三方组件 API、交互、浏览器兼容性、可访问性均已验证。实际使用仍需按模块已安装版本核对导出、类型、样式和业务回归。普通检查不联网；更新通过显式指定 source checkout 和 commit 完成。
