## 规范和工具

根 AGENTS 最前两节明确要求 AI 第一操作先读规范，以及 main/release-/prev-/预发布@SHA/人工试用门禁。完整定义在 [AGENT-START](../conventions/AGENT-START.md)、[RELEASES](../conventions/RELEASES.md)。根 README、docs入口、贡献、提交、测试、部署、模块文档同步指向统一规则。

`scripts/release-policy.mjs` 是离线只读规划器：校验 tag 语法、版本、main来源、prev基准可达性、@展示和拒绝错误降版。输出始终包含 deploymentAuthorized:false，不创建tag、不改版本、不连接服务器，不将可填写字段当作人工批准。`pnpm release:plan --help` 查看入口。

[CI/CD设计](../ops/CICD.md) 区分机器验证、候选试用、日常预发布、tag里程碑、正式发布和人工回滚。当前没有启用 GitHub Actions 工作流或远程审批/部署凭据，不能称为已能自动发版；后续先确认可信审批、预发布隔离和目标适配器。
