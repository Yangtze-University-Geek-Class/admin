## 需要注意的兼容性变化

新设置的密码至少 15 个字符且 UTF-8 不超过 72 字节，旧密码仍可登录；SVG 上传/读取被拒绝，GIF 只保留首帧；开发 mock 明确只读；Node 基线为 22 且最低 22.13；旧自动部署脚本仅保留 --check 预检。以上不是静默的格式重构，使用和运维文档已说明。

OAuth 的 callback URL、既有会话 Cookie 名和业务 API 路径未改名。状态 Cookie 从未签名载荷升级为签名且服务端检查有效期；发布时已进行中的旧授权需重新发起。GitHub 绑定仅允许同一有效浏览器会话完成，成功后撤销旧论坛会话并签发新会话。此行为变化已同步 API、安全、用户指南和部署说明。

未强行升级 React/Vite/Tailwind 大版本，未引入微服务、SSR、ORM 或容器编排。查询 key 仍保持现有形状，本轮修复必要分页参数与退出清理，不宣称全量工厂迁移。历史代码的宽类型和部分重复逻辑尚可继续逐模块收敛，不以自动删改全部 any 追求表面一致。
