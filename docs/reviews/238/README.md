## 验证边界

`tests/e2e/competitions.spec.mts` 为 CI 提供两尺寸、真实路由与内存库的编辑/下线/恢复回归；具体运行结果以 PR 对应提交的检查页为准。本机先使用 ego-browser，任务空间不可用后以 Codex 内置浏览器复查最终构建并截图。没有把截图、模拟身份、代码检查或 Netlify 样板视为真实 GitHub OAuth 往返、所有者验收或上线证明。报名组队和新的 SSO 身份模型未在此 PR 实现。

最终复核补齐了 Unicode 字数口径，并修复 CI 浏览器测试的 ESM 加载方式。完整验证重新通过；扩展汉字的拒绝和长度边界由真实路由与表单回归核对，本地浏览器也实际输入单个扩展汉字验证提示。上述截图所展示的布局、状态和操作保持一致；新的浏览器测试运行结果仍以 PR 对应提交的 CI 为准。

机器人关于跨年日期的意见已在源码复现：原 shortDay 删除了所有年份。现按当前北京年份显示短日期、跨年保留完整日期，并覆盖 UTC 尚未跨年但北京时间已跨年的边界。本地新增一条虚构跨年赛事，手机筛选和图像核对均无横向溢出；该图是第10张证据。
